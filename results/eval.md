# Evaluation: single-prompt baseline vs agent

> **Caveat.** These results use the mock LLM provider. They validate the pipeline, the MCP tools, the safeguards and the scoring end to end, not LLM hunting capability: the agent and baseline mocks are author-scripted heuristic playbooks (they pivot only on values returned by tool calls, never on the labels, but a human wrote the pivots). Run `--provider anthropic` to measure a real model.

> **Unequal budget.** The `baseline` row sees one prompt of ~17,575 input tokens (estimated, ~4 chars/token) per hunt; the `agent` consumes ~71,959 cumulative input tokens per hunt (it re-sends its growing history on every call). `baseline_matched` is the same baseline given a log sample sized to the agent's input tokens for that hunt, so the agent-vs-baseline gap can also be read at equal token budget.

Generated by `make eval` on 2026-11-15 13:40 UTC. Provider: `mock`. Seeds: 7, 21, 42. Values are means over seeds; `n/a` = no rule/evidence for that technique, so precision is undefined. Rule metrics come from running each proposed rule through the Sigma validator over the full logs. Per-run rows: `eval_techniques.csv`, `eval_cost.csv`.
